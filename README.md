## About

I'm **@datanestpy**, a Python developer and Excel automation specialist. I build scripts and tools that take over repetitive spreadsheet work: cleaning messy data, combining files and producing reports, so the job gets done the same way every time.

## What I Do

- **Excel automation**: scripts that read, transform and write spreadsheet files
- **CSV processing**: converting, filtering and restructuring large exports
- **Data cleaning**: duplicates, missing values, inconsistent formats and stray whitespace
- **Spreadsheet merging**: combining many files into one consistent dataset
- **Automated reporting**: summaries, totals and charts generated from raw data
- **Custom Python scripts**: small tools built around your workflow and file formats

## Featured Projects

Three working demos on the [portfolio site](https://kurosaki-zangetsu.github.io). They use **fictional data**, are **not client work**, and run entirely in your browser. Files are never uploaded anywhere.

### Excel Data Cleaner
Removes duplicate rows, flags missing values, trims whitespace and standardizes column names. Preview the result and download the cleaned CSV.
[Try the demo](https://kurosaki-zangetsu.github.io/#cleaner)

### Spreadsheet Merger
Upload several CSV files, match their columns, preview the combined data and export one merged CSV. Files with different columns are handled with a clear warning.
[Try the demo](https://kurosaki-zangetsu.github.io/#merger)

### Automated Sales Reporting
A sales dashboard built from fictional orders: revenue, order counts, average order value, a monthly chart and best-selling products. Change the reporting period and download the report as CSV.
[Try the demo](https://kurosaki-zangetsu.github.io/#sales)

> The browser demos work with CSV files only. My Fiverr work uses Python with pandas and openpyxl, including Excel (.xlsx) workbooks.
